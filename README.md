# OptimizerByforaaDev

Download the latest Windows installer from the [Releases](https://github.com/TiagoDev88/OptimizerByforaaDev-Downloads/releases) page.

OptimizerByforaaDev is a Windows WPF tool for PC diagnosis, CS2 benchmark comparison and reversible performance profiles.

The installer requires a provisioned owner PIN. The source repository is maintained separately.
